# Visual diff fixtures

Each fixture directory contains one complete report bundle. The web app serves
these bundles as static files only in development. Production builds exclude
them.

`mixed` is generated by the real comparison package. It covers one changed,
added, removed, and unchanged screenshot. Do not edit its report or PNG files
by hand.

Run `pnpm fixture:generate` after an intentional producer change. Run
`pnpm fixtures:check` to validate every report with the Zod contract and ensure
that each referenced PNG exists with no unreferenced PNG files.
